# InkTrace“接着写”使用说明

这份说明写给小说作者，不需要懂模型、接口或任何技术词。

## 它能做什么

当你已经写完一部分正文，不知道下一章怎么落笔，或者想先看一个可能的方向时，可以用“接着写”生成一份新稿。

它只会写一份独立的新稿，不会直接改动你的正文。

## 怎么使用

1. 打开你的作品和想继续写的章节。
2. 打开右侧的“AI”。
3. 选择“接着写”。
4. 回答“下一章，你最想看到什么？”

你可以选择：

- 让冲突更紧张；
- 让人物关系推进；
- 把刚才的伏笔接下去；
- 或者自己写一句想法。

如果你没有特别要求，直接点“不用补充，直接接着写”即可。

5. 点击“写一章给我看”。
6. 等新稿写完后先阅读，再决定下一步。

## 写完以后怎么办

新稿写完后，它还没有进入你的正式正文。你可以：

- 看看新稿是否符合故事方向；
- 满意时，明确选择把它放进正文；
- 不满意时放弃，原正文不会受到影响；
- 决定是否继续写下一章。

“继续写下一章”不等于采用当前新稿；“放进正文”也不会自动触发下一章。两个决定彼此独立。

## 三个方向是什么意思

### 让冲突更紧张

适合当前章节已经有矛盾，希望局势升级，但暂时不想解决核心问题时使用。

### 让人物关系推进

适合希望两个人的信任、误解、感情或立场发生变化时使用。

### 把刚才的伏笔接下去

适合前文刚出现一个物件、秘密、异常行为或未解问题，希望下一章继续承接时使用。

这些选项只是帮你快速写一句要求。选完后仍可以修改输入框里的文字。

## 什么是“更多保护设置”

普通使用不需要打开它。这里放的是：

- 最多准备写几章；
- 希望控制的大致篇幅；
- 到达用量上限时是否停下来；
- 发现严重矛盾或伏笔被提前揭开时是否停下来。

无论这些设置如何变化，系统都不会替你把新稿自动放进正文。

## 常见问题

### 为什么按钮不能点？

先确认已经打开具体章节，并且在设置页完成了 AI 模型配置。

### 为什么写完后正文没有变化？

这是正常的。系统会先把内容放在新稿区，只有你明确选择“放进正文”后才会应用。

### 它会不会自己一直写下去？

不会。每写完一章都会停下来等你决定。

### 不满意会破坏原稿吗？

不会。未采用的新稿与正式正文隔离。

### 我写的那句话会出现在日志里吗？

系统不会把完整写作想法、正文、新稿、Prompt、ContextPack 或 API Key 记录到普通日志中。

## 最重要的原则

你始终是作者。InkTrace 负责准备选项和新稿，故事往哪里走、哪些内容进入正文，最终都由你决定。
